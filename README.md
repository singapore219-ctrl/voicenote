# AI 녹음노트

회의를 녹음하면서 **실시간으로 글로 받아쓰고**, 끝나면 **요약**까지 만들어 주는 웹앱입니다.
설치형(PWA)이라 갤럭시탭 홈 화면에 앱처럼 올라갑니다.

## 기능

| 기능 | 설명 |
|---|---|
| 녹음 | 마이크 녹음, 일시정지/재개, 음량 미터, 끝나면 오디오 파일 저장 |
| 실시간 전사 | 말하는 즉시 한국어 받아쓰기, 문장마다 `00:28` 타임스탬프 |
| 되듣기 | 타임스탬프를 누르면 그 지점부터 녹음 재생 |
| 수정·표시 | 문장을 눌러 직접 교정, ★로 중요 발언 표시 |
| 자동 요약 | 인터넷·키 없이 즉시 — 핵심요약·키워드·결정사항·실행항목·이슈 |
| AI 요약 | 설정에 Claude API 키를 넣으면 정식 회의록(한줄요약/논의/결정/실행표) 생성 |
| 내보내기 | 회의록 `.md`, 전사문 `.txt`, 오디오 파일, 클립보드 복사 |
| 기록 보관 | 지난 회의 50건까지 기기 안에 저장 |

단축키: `Ctrl+Space` 녹음 토글 · `Ctrl+S` 요약

## 태블릿에 설치하기

1. 갤럭시탭에서 **Chrome**으로 배포 주소를 엽니다. (삼성 인터넷은 음성인식 미지원)
2. 하단 **📲 앱 설치** 버튼, 또는 Chrome 우측 상단 `⋮` → **앱 설치**
3. 홈 화면 아이콘으로 실행 → 첫 녹음 때 마이크 권한 **허용**

설치 후에는 오프라인에서도 앱이 열립니다. 단, 실시간 전사는 인터넷이 필요합니다.

## PC에서 쓰기

`실행.bat` 더블클릭 → 브라우저가 `http://localhost:8765` 로 열립니다.
(HTML을 파일로 직접 열면 브라우저가 마이크를 차단하므로 반드시 이 방식으로 실행)

## 알아둘 점

- **Chrome / Edge / Safari 전용.** 실시간 전사는 브라우저 내장 음성인식을 사용합니다.
- **전사에는 인터넷이 필요합니다.** 사내망에서 막히면 "네트워크 오류"로 표시되며, 이때도 녹음과 요약은 정상 동작하므로 오디오만 저장해 두면 됩니다.
- **녹음 중에는 화면을 켜 두세요.** 화면이 꺼지면 녹음과 인식이 중단됩니다. (앱이 화면잠금을 자동으로 막지만 절전 설정이 강하면 꺼질 수 있습니다)
- **데이터는 기기 안에만 저장됩니다.** 녹음·전사·API 키 모두 서버로 올라가지 않습니다. AI 요약을 켠 경우에만 전사문이 Anthropic API로 전송됩니다.

